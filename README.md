# Next.js Learning Journey 🚀

My journey of learning **Next.js from beginner to advanced**, following the [Next.js Tutorial — Beginner to Advanced]

This repository contains my learning progress, hands-on practice, personal notes, interview revision materials, and projects built while learning Next.js.

The goal is not just to complete a tutorial, but to understand the concepts, practice them independently, and apply them to real-world applications.

## 🎯 Learning Goals

- Understand Next.js fundamentals and the App Router.
- Learn file-based routing, layouts, dynamic routes, and navigation.
- Understand Server Components and Client Components.
- Explore rendering strategies, streaming, and Suspense.
- Learn data fetching, database integration, and data mutations.
- Practice Server Actions, forms, validation, and optimistic updates.
- Implement authentication and role-based access control.
- Build practical applications using Next.js.
- Maintain concise notes for technical interviews and future revision.
- Deploy applications to Vercel.

## 🧪 Practice and Projects

I will use the `practice/` directory for lesson examples, experiments, and small exercises.

The `projects/` directory will contain applications that combine multiple concepts learned throughout the course.

My practice approach:

1. Watch a lesson and understand the concept.
2. Recreate the example independently.
3. Experiment with the code and explore edge cases.
4. Write down key takeaways in `notes.txt`.
5. Update `learning-roadmap.md`.
6. Commit the changes to GitHub.
